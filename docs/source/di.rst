DI
--

The library supports integration with the dishka_ dependency injection framework, allowing developers to manage
application dependencies and their lifecycles in a consistent and structured way.
It enables dependencies such as database connections, application services, and configuration
objects to be provided to task executions through dependency injection, reducing the need for manual dependency
management and simplifying integration with existing applications.

.. _dishka: https://dishka.readthedocs.io/
